# Electrical Schematics

Place the actual electrical schematics here.

### Example

```text
electronics/schematics/system/RG-ELEC-SYS-001.pdf
electronics/schematics/images/RG-ELEC-SYS-001.png
```

Keep native source files from KiCad, Altium, Proteus, EasyEDA, etc. when
available. The PDF is for technical viewing and the PNG/JPG is for quick
GitHub preview.
