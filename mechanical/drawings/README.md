# Mechanical Drawings

Put the real mechanical drawings from the RailGard project here.

## Suggested categories

| Your document | Folder |
|---|---|
| Full robot assembly | `assembly/` |
| Chassis assembly | `assembly/` |
| Robotic arm assembly | `assembly/` |
| Individual part | `parts/` |
| Exploded view | `exploded_views/` |
| Dimensioned drawing | `dimensions/` |
| PDF version | `pdf/` |
| PNG/JPG preview | `images/` |

Do not create a drawing just because a folder exists. These folders are
containers for your actual project drawings.
