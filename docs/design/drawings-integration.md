# Integrating RailGard Engineering Drawings

The repository should keep three representations when available:

1. **Native engineering file** — CATIA, SolidWorks, KiCad, Altium, Proteus, etc.
2. **PDF technical drawing** — readable/downloadable engineering document.
3. **PNG/JPG preview** — convenient visual preview inside GitHub.

## Mechanical

```text
Native CAD
   ↓
mechanical/cad/
   ↓
mechanical/drawings/pdf/
   ↓
mechanical/drawings/images/
```

## Electrical

```text
Native schematic
   ↓
electronics/schematics/
   ↓
electronics/schematics/pdf/
   ↓
electronics/schematics/images/
```

## Wiring

```text
Native wiring document
   ↓
electronics/wiring/
   ↓
electronics/wiring/pdf/
   ↓
electronics/wiring/images/
```

The PNG/JPG is not a replacement for the original technical drawing.
