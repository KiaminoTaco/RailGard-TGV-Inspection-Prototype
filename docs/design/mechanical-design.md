# Mechanical Design

## Scope

The mechanical engineering work described for RailGard includes:

- chassis architecture;
- CATIA V5 modelling;
- structural dimensioning;
- Resistance of Materials (RDM);
- stability considerations;
- mass estimation;
- centre-of-gravity considerations;
- mechanical assembly;
- integration of actuated subsystems.

## Robotic arm

The project also studies a multi-axis robotic arm, including:

- mechanical design;
- kinematic study;
- torque calculations;
- actuator integration;
- interface between the robotic subsystem and the main platform.

## Recommended repository contents

Place source engineering files in:

- `mechanical/cad/`
- `mechanical/drawings/`
- `mechanical/calculations/`

For each major calculation, add a short Markdown note explaining the
objective, assumptions, equations, inputs, results and limitations.
