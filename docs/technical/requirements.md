# Engineering Requirements

The technical dossier describes a constrained undercarriage inspection
environment and identifies the following target parameters for the proposed
robot:

- available rail gauge: 1435 mm;
- undercarriage height identified in the study: 1500 mm;
- target inspection distance: 200 m;
- target autonomy: 4 hours;
- inspection operation duration discussed: 1 hour;
- target movement speed discussed: approximately 1 m/s.

These values are project study targets, not certification requirements.
