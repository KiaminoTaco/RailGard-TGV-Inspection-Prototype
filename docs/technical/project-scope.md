# RailGard — Project Scope

## 1. Project identity

**Project:** RailGard  
**Domain:** Railway inspection robotics  
**Application concept:** TGV undercarriage inspection  
**Project type:** Engineering / experimental prototype

## 2. Problem addressed

The project studies a robotic solution intended to support inspection of the
area underneath TGV trainsets in maintenance conditions.

The technical dossier describes manual inspection as a task that can be
complex and risky and proposes a robotic platform intended to assist
inspection, detect faults, and locate them.

## 3. Engineering scope

The documented project covers:

- mechanical structure and dimensioning;
- multi-axis robotic manipulation;
- embedded electronics;
- motor and actuator control;
- battery/power integration;
- sensing;
- communication between subsystems;
- image acquisition and inspection concepts;
- autonomous/navigation concepts;
- monitoring and data acquisition.

## 4. Important project status

RailGard should be presented as an engineering prototype / experimental
platform.

The repository must not claim:

- deployment on operational TGV trains;
- railway certification;
- industrial approval;
- replacement of certified inspection procedures;
- completion of all validation required for real railway operation.
