# Security and Sensitive Information

This repository is intended for public technical documentation.

Before committing files, check that they do not contain:

- passwords or usernames used for private systems;
- API keys or access tokens;
- private certificates or SSH keys;
- personal/private contact information not intended for publication;
- local configuration containing credentials.

The technical dossier used during development contained access credentials in
one section. Those credentials must not be reproduced in this public
repository.
